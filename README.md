# LEX Blaine — локальный прототип

LEX собирает документы из публичного раздела форума Blaine, индексирует их и отвечает на вопросы с цитатами. Проект намеренно не содержит заранее выдуманных законов: до запуска сборщика база пуста.

## Что входит
- `scrape_forum.py` — обходит все страницы указанного раздела, находит темы законов, загружает их и сохраняет тексты/URL/заголовки/время сбора в `data/laws.json`.
- `app.py` — локальный веб-сервер, поиск по фрагментам и optional LLM-объяснение на сервере.
- `templates/index.html` — адаптивный интерфейс LEX.
- `requirements.txt` — зависимости.

## Запуск (Windows / macOS / Linux)
Требуется Python 3.10+.

```bash
python -m venv .venv
```
Windows:
```bash
.venv\Scripts\activate
```
macOS/Linux:
```bash
source .venv/bin/activate
```
Затем:
```bash
pip install -r requirements.txt
python scrape_forum.py
uvicorn app:app --reload
```
Открой `http://127.0.0.1:8000`.

## ИИ (необязательно)
Без ИИ приложение всё равно ищет совпадающие статьи и показывает первоисточники. Для LLM-объяснения можно задать `OPENAI_API_KEY` в переменных окружения на компьютере, где запущен сервер, и `OPENAI_MODEL` (по умолчанию `gpt-4.1-mini`). Ключ не вводится в браузер и не записывается в HTML. Потребуется доступ к API и действующая оплата/квота.
Windows PowerShell (только для текущего окна):
```powershell
$env:OPENAI_API_KEY="твой-ключ"
$env:OPENAI_MODEL="gpt-4.1-mini"
uvicorn app:app --reload
```
macOS/Linux:
```bash
export OPENAI_API_KEY="твой-ключ"
export OPENAI_MODEL="gpt-4.1-mini"
uvicorn app:app --reload
```

## Как обеспечивается точность
- Каждый результат включает ссылку на исходную тему и извлечённый текст.
- Если источников мало или поиск слабый, интерфейс сообщает о недостатке данных.
- LLM получает только найденные выдержки и обязан ссылаться на них; это снижает, но не исключает ошибки.
- Сборщик сохраняет заголовок, URL и дату сбора; проверяй, что форум не изменил структуру страниц.
- Для строгой проверки новых редакций повторно запускай `python scrape_forum.py`. Не удаляй старую выгрузку, если нужно сравнить версии: скопируй `data/laws.json` перед повторным запуском.
- У сборщика есть задержка между запросами; он использует только публичные страницы и не обходит авторизацию/ограничения доступа.

## Ограничения прототипа
- Это не опубликованный сайт; сервер запускается локально на твоём устройстве.
- Полнота сбора зависит от доступности форума и его HTML-разметки в момент запуска. После сбора проверь число тем и ошибки в `data/scrape_report.json`.
- Документы с одинаковыми названиями/старыми редакциями не считаются автоматически юридически эквивалентными: при противоречиях LEX должен показывать обе нормы и просить проверить актуальную редакцию.
