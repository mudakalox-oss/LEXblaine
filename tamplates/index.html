Как устроен LEX

Поиск по тексту и ИИ-разъяснение — два отдельных этапа.

1. Сбор источников

Сборщик проходит страницы категории, скачивает доступные темы и сохраняет заголовки, тексты, ссылки и отметку времени.

2. Поиск (RAG)

Вопрос разбивается на термины; фрагменты ранжируются по совпадениям и редкости слов. В ответ попадают наиболее релевантные выдержки.

3. Объяснение ИИ

Если API-ключ задан в переменных окружения сервера, модель объясняет только найденные нормы. Ключ не передаётся браузеру.

4. Проверка

Каждый результат содержит ссылку на исходную тему. При споре между редакциями нужно сверять даты и первоисточники вручную.

Автоматический сбор может пропустить документ при изменении разметки форума. Смотри отчёт сканирования и проверяй ошибки перед использованием.
